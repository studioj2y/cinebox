## 1. 结论

整体完成度**高**：首屏影院氛围、答题的"溶解→浮现→上浮入流"四阶段过场、结果页杂志式排版，都明显高于同类
小工具的水准，触摸目标、三态反馈（loading/done/error）、防重入等工程细节也齐备。**方向不需要重做。**

问题集中在三类，均可低成本修好：

1. **2 个确定性缺陷**（`已验证`，有截图）：移动端品牌字标与「返回」按钮重叠；结果页二维码卡在未解读前就露出。
2. **过场节奏偏重**：每题强制锁输入 2850ms，5 题累计约 14.25s 不可跳过；且选项在题与题之间垂直漂移 214px。
3. **无障碍/一致性缺口**：`prefers-reduced-motion` 未覆盖海报墙无限滚动与 JS 过场；键盘无可见焦点；进度条与题号语义不一致。

## 3. 问题与修订（按优先级）

### P0 — 确定性缺陷（建议先修）

> ✅ **P0-1 / P0-2 / P1-8 / P2-10 已于当日修复**，实测复验通过（桌面 8/8、移动 9/9）。修复内容与实测数据见 §7。

**P0-1 移动端：品牌字标压住「← 返回」按钮**
- 现象：390px 宽下 `CINEBOX` 与返回按钮**重叠 65×14px**，字直接印在按钮上。桌面 1440px 下不重叠（间隔 272px）。
- 证据：`verified`．实测 `.brand-mark`=[22,50,89,64]，`#backBtn`=[24,48,108,92]。
- 根因：`.brand-mark{position:fixed;top:50px;left:22px}` 与答题屏 `.quiz-top`（含返回按钮）在窄屏落在同一视觉区。
- 修订（任选）：
  - A（推荐）：`#quiz.active ~ .brand-mark` / 或给 `#quiz` 加态时，令 `.brand-mark` 在答题屏隐藏（答题屏已有返回入口，品牌字logo冗余）；
  - B：窄屏把 `.brand-mark` 移到右上或缩小并抬高到 `top:10px`，避开 `quiz-top`。

**P0-2 结果页：二维码卡在未点「不良有话说」时就已可见**
- 现象：刚进入结果屏，二维码卡「扫码关注不良少女放映组」就出现在页面里；而设计意图是**解读完成后**才浮现。
- 证据：`已验证`．未点解读时 `#qrCta` 的 `hidden` 属性为 `true`，但 `getComputedStyle.display === "flex"`、`opacity: 1`、实测渲染尺寸 470×264（桌面）/ 346×271（移动）——即**属性隐藏但视觉可见**。
- 根因：`.qr-cta{display:flex}` 覆盖了 UA 的 `[hidden]{display:none}`。CSS 已给 `.poster-area/.poster-status/.poster-img` 补过 `[hidden]` 规则（见 `style.css` 注释），**唯独漏了 `.qr-cta`**。
- 修订：把选择器补全为
  `.qr-cta[hidden], .ai-prompt[hidden] { display: none !important; }`
  （`#aiPrompt` 当前无恙——`display:none` 实测生效——但一并纳入可防回归）。

### P1 — 体验问题（改动小、收益大）

**P1-3 每题过场强制锁输入 2850ms，不可跳过**
- 证据：`已验证`（代码常量）．`chooseOption` 时间线 = 溶解 → +520ms 幽灵形成 → +950ms → 停留 260ms → 上浮 800ms → 停顿 320ms = **2850ms/题**，期间 `quizLocked=true` 吞掉所有点击。5 题累计 **≈14.25s**。
- 判断：与「即时触控反馈应快速、可中断，不等待装饰结束」相悖；连续快答的用户会被明显"卡"。
- 修订：
  - 把 `T_NEXT` 压到 ~1400–1800ms（form 600ms / 停留 160ms / lift 480ms / 停顿 260ms）；
  - **允许点击加速**：过场期间再点画面即立即推进到下一题（保留最少 400ms 反馈），并保留首题的完整演示，让"慢即是慢、快可跳"。

**P1-4 选项在题与题之间垂直漂移 214px**
- 证据：`已验证`．移动端第一个选项 y 坐标 q1=297 → q3=511（漂移 **214px**）；根因是顶部 `.reply-stream`（max-height 34vh）随回复累积增高，把问题卡整体下推。
- 影响：同一个「第一个选项」在不同题位于不同高度，破坏肌肉记忆，快答时易误点。
- 修订：把回复流改为**固定高度**（如固定 3 行槽位，超出才滚动）或**内滚动不撑高**，使问题卡与选项位置在各题间保持稳定。

**P1-5 `prefers-reduced-motion` 覆盖不全**
- 证据：`已验证`（CSS + JS）．现有规则只停了 `.fx-aurora / h1 / marquee / result-poster / poster::after / #progressBar::after / .reveal-btn / .hero-step .dot`。
- 缺口：① **海报墙 4 行无限滚动**（`.wall-row.r1–r4`）未关——这是全站最大的持续运动；② JS 里 2850ms 过场用的是 `transition` + `setTimeout`，不触发 `animation:none`，reduced-motion 用户照样等满。
- 修订：reduced-motion 下 ①对 `.wall-row` 设 `animation:none` 并加一层静态暗化；②`app.js` 读取 `matchMedia('(prefers-reduced-motion: reduce)')`，命中时把过场时长降为 0（直接切换、回复即时落入流）。

**P1-6 键盘可见焦点缺失**
- 证据：`已验证`（CSS）．`.cta/.ghost/.opt` 均无 `:focus-visible` 规则，Tab 到按钮时无可视指示。
- 修订：补 `:focus-visible { outline: 2px solid var(--accent2); outline-offset: 2px; }`（`.opt` 可换 `border-color` + 外发光），并确保顺序合理。

**P1-7 总结屏信息重复**
- 证据：`已验证`（截图 d-04）．5 条回复在**顶部回复流**已展示一遍，总结卡里又以胶囊**重复**一遍。
- 修订：二选一——总结卡只显示"你刚才说——"的聚合数量 + 情绪归纳，或让回复流在总结态收起，把焦点让给「揭晓今晚的电影 →」主按钮。

**P1-8 进度条与题号语义不一致**
- 证据：`已验证`（代码 + 截图）．`#progressBar` 宽度 = `idx/QUIZ_N`（第 1 题时 0%），旁边文字 = `idx+1`（显示 `1/5`）。同一屏出现"进度 0% / 题号 1"的错位。
- 修订：统一为「进度 = 已完成」并让文字也说完成数（`已完成 0/5`），或把条改为 `(idx+1)/QUIZ_N` 与题号对齐。推荐前者（进度条表示"走过的路"更符合直觉）。

## 4. 动效规范（游戏 UI 动效）

现状盘点与建议（`事件 → 功能 → 建议时长/曲线 → 中断 → 降级`）：

| 事件 | 功能 | 现状 | 建议 |
| --- | --- | --- | --- |
| 极光漂移 | 氛围 | 26s/32s，transform，常驻 | 保留；reduced-motion 关 |
| 海报墙滚动 | 氛围/片库体量 | 1200–2000s linear 无限，hover 暂停 | 保留；**reduced-motion 必关** |
| 标题流光 | 品牌强调 | 7s 循环 | 保留 |
| 选项点按确认 | 反馈 | **无瞬时确认**，点击后 520ms 才开始幽灵形成 | **新增**：点击瞬间给被选项 ~120ms 按下态（缩放/发光），先确认"收到了"再过场 |
| 问题卡溶解 | 层级退出 | 850ms | 收到 ~520ms |
| 回复幽灵浮现 | 奖励强调 | form 950ms + 停留 260ms | 收到 form ~600ms，停留 160ms |
| 回复上浮入流 | 空间连续性 | lift 800ms | 收到 ~480ms；**空间连续性设计保留**（中央→顶部流，是全站最好的动效创意） |
| 新题入场 | 层级进入 | cardIn 1050ms、起点 `translateY(74vh)` | 收到 ~600ms；74vh 位移过大，改 ~40px 位移更克制 |
| 结果错落入场 | 层级进入 | fadeUp 9 项，延迟至 .88s | 保留；末几项延迟可缩 |
| 结果揭晓 | 奖励 | 直接切屏 + 渐入 | 可选增强：海报"模糊→清晰"一次的揭示动作，强化揭晓感 |

**缓动语义目前混用**（`cubic-bezier(.16,.84,.3,1)` 强回弹 / `(.2,.8,.2,1)` 轻回弹 / `ease`），建议归为三档：
`层级切换=标准缓出`、`连续性=位移曲线`、`强调=短回弹`，避免"处处弹性、层级感消失"。

### 修复过程中澄清的两处「伪问题」（避免后续重复排查）

1. **进度条在桌面端一度被测为 22%（低于 40%）**——不是缺陷。定点探针显示 Q2 的 `style.width` 已是 `40%`，而 `getComputedStyle` 仍返回过渡前值；等 `.6s` 宽度过渡真正跑完（约 +1.6s）后实测 `205.6 / 520.1 = 39.5%`。**headless 下 CSS 过渡启动有滞后，测量需等过渡结束**。
2. **桌面端字标与返回按钮"纵向重叠 16px"**——不是重叠。真实相交要求横纵两个方向的重叠都 > 0，此处横向重叠为 0（字标 x≈22–90，按钮 x≈384–468）。
